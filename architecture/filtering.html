🔄 Deduplication Filters

1. Semantic Clustering

ClusterBasedDedup (0.95 threshold - strict):
  - Uses transformer embeddings (128-dim)
  - Euclidean distance calculation
  - Keeps highest-scoring tweet per cluster

ClusterBasedDedup (0.88 threshold - loose):
  - More permissive clustering
  - Allows similar but distinct content

2. Bloom Filter Impressions

ImpressionBloomFilter:
  - Tracks billions of tweet impressions
  - Time-windowed (e.g., 7 days)
  - Memory-efficient probabilistic data structure
  - Filters previously seen tweets

3. Author/Media Deduplication

  • AuthorDedup: Limit 1 tweet per author per batch
  • MediaDedup: Prevent duplicate images/videos
  • ClipClusterDedup: Video clip similarity
  • ConversationDedup: Prevent showing A→B→C and A→C conversations

🎨 Diversity Mechanisms

1. Author Diversity (Exponential Decay)

Parameters:
  decay = 0.5
  floor = 0.25

Scoring:
  1st tweet from author: multiplier = 1.0
  2nd tweet: multiplier = 0.5 + 0.25 = 0.625
  3rd tweet: multiplier = 0.25 + 0.25 = 0.4375
  4th tweet: multiplier = 0.125 + 0.25 = 0.375

Effect: Strong penalty for repeated authors

2. Embedding-Based Diversity (MMR)

Maximal Marginal Relevance:
  - Uses 128-dim transformer embeddings
  - Euclidean distance between candidates
  - Balances relevance vs diversity
  - Iteratively selects dissimilar high-scoring tweets

3. Category Diversity

SimClusters-based:
  - Track community representation
  - log₂-based penalty for repeated topics
  - Ensures varied content across communities

✅ Quality Filters

Engagement-Based

  • MinFavorites: Minimum like count threshold
  • MinScore: Minimum ML score threshold
  • TopK: Select top K by score
  • ConversationQuality: Validate conversation module structure

Author-Based

  • AbuseStrikePercentile: Filter top 2%, 1%, 0.5% abusive authors
  • NSFWTokens: Filter authors with NSFW history
  • AccountAge: Minimum account age requirements
  • FollowerThreshold: "Slop filter" for small creators

Content-Based

  • Language: Match user language preferences
  • Location: Geographic relevance
  • Reply: Filter direct replies (context-dependent)
  • Competitor: Reduce competitor content

📉 Feedback Fatigue

User Feedback Tracking

FeedbackFatigueFilter:
  - Tracks "See Fewer" / "Not Interested" actions
  - Time window: 14 days (configurable)
  - Per-type tracking (author, topic, content type)
  - Gradual weight decay over time

Actions Tracked:
  - Not Interested
  - See Fewer tweets like this
  - Block author
  - Mute author
  - Report tweet

🔑 Filter Pipeline

Pre-Rank Filters

Applied BEFORE ML scoring (fast, broad filtering):

  • Safety filters (NSFW, spam, abuse)
  • Visibility filters (blocks, mutes)
  • Age filters (tweet recency)
  • Language/location filters

Post-Rank Filters

Applied AFTER ML scoring (quality refinement):

  • Deduplication (semantic, author, media)
  • Diversity enforcement
  • Conversation quality validation
  • Final safety checks

🎓 Key Insights

Layered Defense Strategy

  • Multiple Models: Grok + specialized ML models + rules
  • Pre/Post Filtering: Efficient pipeline with quality gates
  • User Control: Respects blocks, mutes, feedback
  • Diversity First: Prevents echo chambers

Why 50+ Filters?

Different filters address different quality dimensions:

  • Safety: Protect users from harmful content
  • Quality: Ensure engaging, valuable content
  • Diversity: Provide varied perspectives
  • Personalization: Respect user preferences
  • Compliance: Legal and policy requirements
