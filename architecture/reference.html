📝 Quick Reference Formulas

Final Score Calculation

For each tweet candidate:
  1. normalized_score_i = score_i / max(all_scores_i)  # Per-head normalization
  2. weighted_score_i = normalized_score_i × weight_i
  3. final_score = Σ(weighted_score_i) + ε  # ε = 0.001
  4. Sort by final_score (descending)

SimClusters Cosine Similarity

score = (userEmbedding · tweetEmbedding) / (||userEmbedding|| × ||tweetEmbedding||)
  
Log-Cosine variant:
score = (userEmbedding · tweetEmbedding) / (logNorm_user × log(1 + norm_tweet))

Author Diversity

multiplier_n = decay^(n-1) + floor
  where n = tweet position from same author
  
Example (decay=0.5, floor=0.25):
  1st: 1.0
  2nd: 0.625
  3rd: 0.4375

PageRank Iteration

PR_next(i) = Σ(PR(j) × w(j,i) / totalWeight(j)) for all j→i
randomPR(i) = userMass(i) × ALPHA + deadPR × (1-ALPHA)
PR_output(i) = randomPR(i) + PR_next(i) × (1-ALPHA)
